# AI-Based Gait Analysis for Early Detection of Knee Osteoarthritis

## Research Overview
This project explores the use of Artificial Intelligence and computer vision for analysing human gait patterns associated with Knee Osteoarthritis (KOA).

The proposed system aims to use smartphone-recorded walking videos to extract gait-related features and identify patterns that may be associated with KOA.

## Research Objectives
- Explore AI-based gait analysis for preliminary KOA screening.
- Extract human body landmarks from walking videos.
- Calculate gait features such as knee angles, step timing, and gait symmetry.
- Develop a machine learning classification approach.

## Proposed Technology Stack
- Python
- MediaPipe Pose Landmarker
- OpenCV
- NumPy and Pandas
- Scikit-learn
- Random Forest
- Matplotlib

## Proposed Architecture
1. Smartphone video collection
2. Video preprocessing
3. Human pose estimation using MediaPipe
4. Gait feature extraction
5. Feature preparation
6. Random Forest classification
7. Screening-oriented output
